### 🔹 **1. React Basics & Core Concepts**

1. **What is React and why is it used?**  
   A JavaScript library for building reusable UI components using a declarative approach.

2. **What is the difference between a class component and a functional component?**

3. **What are props in React?**  
   Props (short for properties) are read-only data passed from parent to child.

4. **What is state in React?**  
   State is mutable data managed within the component.

5. **What is JSX?**  
   A syntax extension that allows writing HTML-like code in JavaScript.

6. **Can a component have both props and state?**  
   Yes.

7. **What is the virtual DOM?**  
   A lightweight in-memory representation of the real DOM used for faster updates.

8. **How does React update the DOM?**  
   Through a process called reconciliation using the virtual DOM diffing algorithm.

9. **What are keys in React and why are they important in lists?**  
   Keys uniquely identify list items and help React optimize rendering.

10. **What are fragments in React?**  
    Used to return multiple elements without adding extra DOM nodes.
