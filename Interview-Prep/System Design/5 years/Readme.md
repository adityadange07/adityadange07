Here are the **Top 50 System Design Interview Questions** tailored for someone with **5 years of experience**, typically expected in **mid to senior-level roles**. These questions cover **high-level architecture**, **scalability**, **database choices**, **microservices**, **APIs**, **real-world use cases**, and **design trade-offs**.

---

## ✅ Top 50 System Design Interview Questions (5 Years Experience)

---

### 🔹 1. Basics of System Design

1. **What is system design? Why is it important?**
2. **How do you approach designing a system from scratch?**
3. **What are the key components of scalable system design?**
4. **What’s the difference between high-level and low-level system design?**
5. **Explain monolithic vs microservice architecture.**

---

### 🔹 2. Core Concepts & Scalability

6. **What is horizontal vs vertical scaling? Which is preferred and why?**
7. **How do you handle a sudden spike in traffic in a web application?**
8. **What is load balancing? What are different types of load balancers?**
9. **How do you make a service fault-tolerant?**
10. **What is caching? Where and how would you use it in a system?**

---

### 🔹 3. Databases & Storage

11. **How do you choose between SQL and NoSQL?**
12. **Explain sharding and its pros/cons.**
13. **What is database replication? What are its types?**
14. **How would you design a system to avoid a single point of failure in DB?**
15. **What is eventual consistency and where is it acceptable?**

---

### 🔹 4. API Design

16. **How do you design a RESTful API?**
17. **What is the difference between REST and GraphQL?**
18. **How would you handle API versioning?**
19. **What are idempotent APIs and why are they important?**
20. **How would you secure APIs in a distributed system?**

---

### 🔹 5. Caching & Performance

21. **How does a CDN work and when would you use one?**
22. **What is a write-through vs write-back cache?**
23. **What strategies would you use for cache invalidation?**
24. **How would you prevent a cache stampede?**
25. **Where would you place caching in a system?**

---

### 🔹 6. Messaging & Asynchronous Systems

26. **Why would you use a message queue in system design?**
27. **What is the difference between RabbitMQ and Kafka?**
28. **How would you design a system for real-time chat or messaging?**
29. **What is event-driven architecture? Pros/cons?**
30. **How would you ensure message processing is idempotent?**

---

### 🔹 7. Real-World Design Problems

31. **How would you design a URL shortener like Bit.ly?**
32. **Design a rate limiter for an API.**
33. **How would you design a notification system (email/SMS/push)?**
34. **Design a high-availability logging system.**
35. **How would you design an online code editor like CodePen or JSFiddle?**

---

### 🔹 8. Advanced Topics

36. **What is CAP theorem? How does it affect system design?**
37. **What is CQRS (Command Query Responsibility Segregation)?**
38. **What is the difference between orchestration and choreography in microservices?**
39. **What is the Saga pattern? When do you use it?**
40. **How would you design a system to handle eventual consistency and retries?**

---

### 🔹 9. Observability & Monitoring

41. **How would you monitor a distributed system?**
42. **What tools or techniques do you use for logging, metrics, and tracing?**
43. **How do you handle alerts for system failures?**
44. **What is a health check endpoint and how should it work?**
45. **What metrics do you monitor to ensure system health?**

---

### 🔹 10. Security & Best Practices

46. **How do you secure user data in a large-scale system?**
47. **What is the principle of least privilege? How does it apply in system design?**
48. **How would you handle user authentication and authorization in a distributed system?**
49. **What strategies would you use to mitigate DDoS attacks?**
50. **How do you ensure data encryption at rest and in transit?**
