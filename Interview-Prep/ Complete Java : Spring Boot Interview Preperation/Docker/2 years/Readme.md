Here are the **Top 50 Docker Interview Questions and Answers** tailored for someone with **around 2 years of experience**. The questions cover **basic to intermediate concepts**, which are typically expected at this level.

---

## ✅ **Basic Docker Interview Questions (1–20)**

### 1. What is Docker?
**Answer**: Docker is an open-source platform used to develop, ship, and run applications inside containers. It allows developers to package applications with all their dependencies.

### 2. What is a Docker container?
**Answer**: A container is a lightweight, standalone, and executable software package that includes everything needed to run a piece of software—code, runtime, libraries, and configuration files.

### 3. What is Docker image?
**Answer**: A Docker image is a read-only template used to create containers. It contains the application and its dependencies.

### 4. How is Docker different from a virtual machine?
**Answer**: Docker uses containers which share the host OS kernel, making them lightweight and faster, whereas VMs include the full OS, making them heavier and slower to start.

### 5. What is Dockerfile?
**Answer**: A Dockerfile is a script containing instructions on how to build a Docker image.

### 6. What is the use of the `docker run` command?
**Answer**: It is used to create and start a container from a specified image.

### 7. What is the difference between `CMD` and `ENTRYPOINT` in Dockerfile?
**Answer**: Both define default commands for a container. `ENTRYPOINT` is preferred for defining the main command, while `CMD` can provide default arguments to that command.

### 8. How do you list all running Docker containers?
**Answer**: `docker ps`

### 9. How do you list all containers including stopped ones?
**Answer**: `docker ps -a`

### 10. How do you stop a running container?
**Answer**: `docker stop <container_id>`

### 11. How do you remove a Docker container?
**Answer**: `docker rm <container_id>`

### 12. How do you remove a Docker image?
**Answer**: `docker rmi <image_id>`

### 13. What is Docker Hub?
**Answer**: Docker Hub is a cloud-based registry where you can find and share container images.

### 14. What is a Docker Volume?
**Answer**: Volumes are used to persist data generated by and used by Docker containers.

### 15. What is the difference between `COPY` and `ADD` in Dockerfile?
**Answer**: `COPY` copies files/directories, `ADD` does that and can also extract tar files and download files from URLs.

### 16. What is the default network driver in Docker?
**Answer**: The default is the **bridge** network.

### 17. What command is used to build a Docker image?
**Answer**: `docker build -t <image_name> .`

### 18. How do you tag a Docker image?
**Answer**: `docker tag <image_id> <repo_name>:<tag>`

### 19. How do you push a Docker image to Docker Hub?
**Answer**:
```bash
docker login
docker tag myimage myrepo/myimage:v1
docker push myrepo/myimage:v1
```

### 20. How do you start a Docker container in the background?
**Answer**: `docker run -d <image_name>`

## ✅ **Intermediate Docker Interview Questions (21–40)**

### 21. What is the difference between bind mounts and volumes?
**Answer**: Bind mounts map to any directory on the host, while volumes are managed by Docker and stored in Docker's internal storage.

### 22. How do you enter a running container?
**Answer**: `docker exec -it <container_id> /bin/bash`

### 23. What is the purpose of `.dockerignore` file?
**Answer**: It excludes files and directories from being copied into the image during `docker build`.

### 24. What is the use of `EXPOSE` in Dockerfile?
**Answer**: It indicates the port on which the container listens for connections.

### 25. What is multi-stage build in Docker?
**Answer**: It helps in creating smaller images by using one stage for building and another for the final image.

### 26. How can you check logs of a Docker container?
**Answer**: `docker logs <container_id>`

### 27. What is the purpose of Docker Compose?
**Answer**: Docker Compose is used to define and run multi-container Docker applications using a YAML file.

### 28. What is the default location of Docker volumes on Linux?
**Answer**: `/var/lib/docker/volumes/`

### 29. What is the difference between `docker exec` and `docker attach`?
**Answer**: `exec` runs a new command in a container, `attach` connects to the main process of the container.

### 30. How do you restart a container automatically if it fails?
**Answer**: Use `--restart` flag like `--restart always`

### 31. Can a container have multiple processes?
**Answer**: Yes, but it's recommended to have one process per container. Still, it's possible using tools like supervisord.

### 32. What is the difference between `RUN`, `CMD`, and `ENTRYPOINT`?
**Answer**:
- `RUN`: Builds the image (executed during build).
- `CMD`: Default command for container (can be overridden).
- `ENTRYPOINT`: Command that always runs (hard to override).

### 33. How do you check Docker version?
**Answer**: `docker version`

### 34. What is the use of the `-p` flag in Docker?
**Answer**: It maps container ports to host ports: `-p host_port:container_port`

### 35. How can you inspect a Docker image?
**Answer**: `docker inspect <image_id>`

### 36. How do you connect containers on the same network?
**Answer**: Use Docker networks and the service/container name to communicate.

### 37. What is the use of `docker stats`?
**Answer**: Shows runtime resource usage statistics for containers.

### 38. Can containers communicate with each other?
**Answer**: Yes, if they are on the same network.

### 39. What is the layered architecture in Docker?
**Answer**: Docker images are made of layers; each instruction in Dockerfile adds a new layer.

### 40. What happens when you delete an image that a container uses?
**Answer**: The image remains as long as the container using it still exists.

## ✅ **Scenario-based & Practical Questions (41–50)**

### 41. How would you troubleshoot a container that keeps restarting?
**Answer**: Check logs using `docker logs`, verify Dockerfile config, check health checks, resource limits, and restart policies.

### 42. How do you update a running container?
**Answer**: You can't directly update a running container. You need to build a new image and run a new container.

### 43. How do you optimize Docker image size?
**Answer**: Use multi-stage builds, minimal base images like `alpine`, clean up unnecessary files in each layer.

### 44. How can you persist data from a container?
**Answer**: By using **volumes** or **bind mounts**.

### 45. How do you handle environment-specific configuration in Docker?
**Answer**: Use environment variables (`ENV` in Dockerfile or `--env` in `docker run`), config files, or secrets.

### 46. How do you share a container setup with others?
**Answer**: Share the Dockerfile or docker-compose.yml file via version control (like Git).

### 47. How do you limit CPU and memory usage in Docker?
**Answer**:
```bash
docker run --memory="512m" --cpus="1" <image>
```

### 48. How do you clean up unused Docker resources?
**Answer**:
```bash
docker system prune
```

### 49. What is the purpose of health checks in Docker?
**Answer**: To ensure the container’s application is functioning as expected. Defined using `HEALTHCHECK` in Dockerfile.

### 50. How do you debug a failed `docker build`?
**Answer**: Use build logs, add intermediate `RUN echo` steps, or run a container from a partially built image to test.
